智能合约部署

编写受限 Python 子集合约，校验后部署上链（部署即创建一笔 deploy 交易）。

合约代码

合约使用 state、msg、emit、require、transfer 等受限 API，禁止 import / IO / 网络。
# 在此编写合约代码 def init(): state["owner"] = msg.sender state["count"] = 0 emit("Created", by=msg.sender) def increment(): state["count"] = state.get("count", 0) + 1 emit("Incremented", value=state["count"]) def get(): return state.get("count", 0)

沙箱安全模型
· AST 静态校验：拒绝 import / dunder 逃逸 / 危险内置
· 受限内置函数白名单（无 open/eval/exec）
· 指令预算：终止死循环与计算爆炸
· 输出上限：限制 print 输出体积
· 状态值 JSON 可序列化 + 键数量上限
